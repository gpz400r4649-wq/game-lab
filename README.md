# つくるラボ / Game Lab

小学生が、自分で部品を追加してゲームを作るためのブラウザ向け試作です。

## 制作の入口

- 新規3D作品は、地面・スタート・基本操作用の射撃銃１つだけです。敵、地形、家、アイテム、ゴール、クリア条件は配置していません。
- 完成したコースやゲームを読み込むお手本はありません。FPS / TPS は視点の切り替えです。
- 「つくる」で部品を置き、動きやルールを選び、「たしかめる」で自分の作品をテストします。
- 新しく置いた敵は動きません。行動タイプや動作ブロックを設定すると追跡・射撃などを始めます。
- 新しく置いたゴールは条件未設定です。クリア条件を自分で選ぶまでクリアできません。
- 2D版も、初期配置はスタートだけです。

以前に保存した作品は維持します。過去のお手本から作った作品も、敵の配置・行動・ゴールの条件を変更せず読み込みます。空の状態から作り直す場合は「空のステージから新しくつくる」を使ってください。必要な作品は先にファイルに保存できます。

## 3D FPS / TPS

入口: https://gpz400r4649-wq.github.io/game-lab/3d.html

UE5のFPS/TPSテンプレートに着想を得た、ブラウザ向けの独立した試作です。UE5自体やUE5のアセットは使っていません。Three.js 0.180.0をMITライセンスで同梱しています（vendor/THREE-LICENSE.txt）。外部CDNへの接続は不要です。

移動、ドラッグによる視点操作、ジャンプ、重力、部品との衝突と着地、TPSカメラの壁へのめり込み回避を用意しています。iPadではスティックとジャンプ・発射ボタン、PCではWASD / 矢印、スペース、Fを使います。

## 追加できる部品

編集画面のグリッドは4m間隔です。標準ブロックは横4m・奥行4m・高さ3m、床は4m四方で、マスにそろって隙間なく並びます。壁はマスの境界に吸着し、タップした端に合わせて向きを決めます。緑・赤の配置プレビューを表示し、上面へのタップは積み重ね、側面へのタップは横への接続になります。移動ボタンは横方向に１マス、標準ブロック・壁・床・屋根の高さ方向に１段ずつ移動します。既存作品の座標や寸法は読み込み時には変更しません。細かな寸法を自分で変更した部品では、標準サイズと異なる形になります。

- 壁・床・屋根・ブロック・足場。配置・複製・回転・位置や大きさの調整ができます。
- 動く足場。方向、範囲、速さを選択でき、乗ったプレイヤーを運びます。
- ジャンプ台。ふれると大ジャンプし、飛ぶ強さを変更できます。
- 敵ロボット。追跡・見はり・射撃・動かない的を選べます。動作ブロックは「さらに工夫する」にまとめています。
- 星・カギ・回復アイテム。得点・取得・回復などの処理を用意しています。カギは取得数で判定し、ドアが開いても消費しません。
- ドア・ゴール。星の数、カギの数、敵の全滅などの条件を選べます。足りないアイテム数は編集画面にヒントを表示します。
- 中間地点。ふれると復活位置を記録し、体力がなくなるとそこから復活します。集めたものや撃破状況を保持します。
- ダメージ床。ダメージ量と床の大きさを調整できます。

これらは部品として用意してあり、新しい作品には配置しません。移動する足場や敵には経路探索を備えていないため、足場の経路が壁を横切らないように配置してください。3D版はWebGL 2対応ブラウザが必要です。実機Safariでのマルチタッチと性能の確認は未実施です。

## 弾の設定・破壊・スロープ

ブロック・壁・床・屋根・動く足場・スロープには、体力（1〜200）と「こわれる / こわれない」を設定できます。弾が当たると体力が減り、0になるとテスト中だけ消えます。命中時の点滅と残り体力を表示します。元の編集用データは変えません。壊した建築は「建築を作品に残す」の対象から外します。

スロープは4方向に回せる4m四方・高さ3mの部品です。低い側からジャンプなしで登れます。編集用の部品と、スロープを出す建築銃を用意していますが、新規ステージには配置・装備しません。

１マスを壁で囲んだ内側にもスロープを置けます。壁の境界との接合や、床とスロープの根元の接合を許可し、置く順番に依存しないようにしています。マス中央を横切る壁やスロープ同士の重複は防ぎます。スロープの上端から、周囲の壁を越えて上階の床へ移れます。

銃の設定:

- 弾の見た目：まるい弾 / ロケット弾。
- 当たったとき：直接ダメージ / 範囲内の敵とブロックに爆発ダメージ / ブロックで最大2回反射。
- 発射間隔：0.08〜2秒。威力：1〜30。同時発射数：1〜8発。
- 弾の直径：0.1〜1.2。速さ：5〜60。広がる角度：0〜45度。爆発範囲：1〜6。
- 建築銃から出すブロックの体力：1〜200。

マシンガンやロケットランチャーの「ヒント設定」を選んでから、各項目を調整することもできます。弾の種類と命中効果は別々に選べます。大きさは当たり判定にも反映し、持ち替えても発射済みの弾の設定は保持します。爆発は同じ弾から1回だけ発生し、自分の体力は減らしません。爆風は範囲内の対象に同じ威力を与えます。

負荷を抑えるため、敵弾も含め画面内96発、演出16個、弾の寿命3秒、反射2回に制限しています。弾が上限に達したら、空きができるまで発射を抑えます。爆発から別の爆発を再帰的に起こす処理はありません。保存データの範囲検証と最大設定の連射テストを実施しています。すべてのiPadでの動作・クラッシュ回避を保証するものではなく、実機確認は未実施です。スコープは未実装です。

## 銃づくりと建築

「持ちもの・銃をつくる」で、名前を付けた銃を最大８個まで登録できます。銃から出るものを「弾」「壁」「床」「屋根」から選びます。新規作品に建築銃は入っていません。以前の作品で持ちもの情報がない場合は、元の武器の性能を引き継いだ射撃銃だけを補います。

- プレイ中は持ちもの欄をタップ、PCは数字1〜8で持ち替えます。
- 建築銃を自分で追加して持つと、狙った場所のプレビューが出ます。緑なら「建てる」/ Fで配置できます。
- 壁・床・三角屋根は4mの間隔と3mの階の高さにそろいます。向き・高さボタン、またはRと[ / ]で調整できます。
- 自分との重なり、重複、遠すぎる位置、ステージ外への配置を防ぎます。射撃の弾数と建築資材は無制限です。
- 「１つもどす」は今回のプレイで建てた最後の部品を取り消します。
- **「建築を作品に残す」**で建てた部品を編集用の作品へ加え、自動保存して編集へ戻ります。押さずに編集へ戻る・再挑戦する・ページを閉じると、プレイ中の建築は消えます。敵の撃破・アイテム取得状況は編集用の作品に保存しません。

部品数は元のステージとプレイ中の建築を合わせて150個まで。窓や入口の編集、資材集め、オンライン対戦は未実装です。屋根は三角柱として当たり判定を持ちます。

## 保存と2D版

作品はブラウザに自動保存し、JSONファイルとして保存・読み込みできます。共有端末ではファイルにも保存してください。2D・3Dは別の保存領域を使います。サイトデータ削除やプライベートブラウズでは保持されない場合があります。

2D版は https://gpz400r4649-wq.github.io/game-lab/ から開けます。移動・発射・自動照準・当たり判定、敵の動作ブロック、部品配置・カメラ追従などを用意しています。新規作品の配置はスタートだけです。2D版のゴールは、追加すると敵の全滅後に到達してクリアする部品です。

## 取ったとき・ふれたときのイベント

星・カギ・回復・ドア・中間地点・ゴールを選ぶと「イベントをつくる」が表示されます。見た目と役割を分け、元の効果を変更したり、起きることを最大6個まで組み合わせられます。元の効果をすべて外すことも、「元の役割にもどす」こともできます。

- 星・カギ・回復：ふれて取ると発生します。回復だけの設定は従来どおり体力が減ったときだけ拾えます。別のイベントを加えると、満タンでも拾えます。
- ドア：設定した条件を満たすと発生します。開ける効果を外して、別の役割にすることもできます。
- 中間地点：ふれると発生します。記録に加えて銃をもらうなどを設定できます。
- ゴール：ふれて、設定した条件を満たすと発生します。クリア以外の役割にも変えられます。条件未設定では発生しません。

起きること：星の数を増やす、カギの数を増やす、得点を増やす、回復、指定したドアを開く、指定した銃を拾う、待機中の敵を出現させる、その場所を中間地点にする、クリアする。

「星を拾う → ロケットランチャーをもらう ＋ 敵が出現する」の作り方：

1. 「持ちもの・銃をつくる」で銃を用意し、「この銃をいつ使える？」を「イベントで拾って使う」にする。
2. 出現させたい場所に敵を置き、「いつ出現する？」を「イベントで出現を待つ」にする。行動タイプは別途選ぶ。
3. 星を置き、イベントを「設定した銃をひろう」「待機中の敵を出現させる」に変更して、それぞれの対象を選ぶ。
4. 「たしかめる」で星を取る。銃は拾うまで選択・発射できず、出現待ちの敵は表示・移動・攻撃・被弾をしません。

各部品のイベントはテストプレイにつき1回だけ起きます。敵は複製して増やすのではなく、配置済みの1体を有効にします。全滅条件には出現待ちの敵も含めます。ドアを開ける効果から別のイベントを再帰的に発生させる処理はありません。対象が削除された場合は設定画面に案内を出し、その効果だけをスキップします。

取得した銃・出現・回復・ドアの開閉・イベントの実行済み状態は編集作品を書き換えず、「やりなおす」で初期状態に戻ります。イベント未設定の保存済み作品は、元の星・カギ・回復・ドア・ゴールの効果を引き継ぎます。新規ステージは引き続き空です。


## iPadの同時タッチ操作

プレイ画面では移動スティック・視点ドラッグ・発射・ジャンプのタッチをゲーム操作として扱い、Safariのピンチ／ダブルタップ拡大や長押しメニューとの競合を抑えています。CSSの `touch-action` に加え、キャンセル可能な Touch/Gesture イベントを非passiveリスナーで処理します（[Appleのイベント資料](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/HandlingEvents/HandlingEvents.html)）。ゲーム画面内のタッチをdocumentのcapture段階で処理し、片方の指をスティックに残したまま別の指で連打する場合も、残る指の数にかかわらずtouchendを抑止します。通常の持ち替え・やりなおすボタンは、移動していないタップを1回のクリックとして処理します。持ちもの欄の横ドラッグも専用処理で維持します。プレイ中はルート要素にもtouch-action:noneを指定し、viewportの拡大制限を補助的に設定します（Safariのバージョンによってviewport制限が無視される場合があるため、これだけには依存しません）。編集・設定に戻ると元のviewport設定へ復元します。HTMLが読み込むアプリ・CSS・入力モジュールには更新番号を付け、旧ファイルのキャッシュを避けています。

入力は指のIDで管理し、別の指の終了でスティックや視点を解除しません。発射ボタンに複数の指が触れた場合は最後の指を離すまで連射を維持し、キャンセル・画面切替・フォーカス喪失時には解除します。イベント処理の自動テストは実施していますが、iPad実機での同時タッチとSafariのズーム抑制は未検証です。


## 小学生向けのよみがな

3D版の説明文・設定ラベル・イベント・ゲーム中の案内には、漢字の上にふりがな（HTML ruby）を付けています。短いボタンとネイティブの選択肢はひらがな表示にし、読みを併記して横に長くなりすぎないようにしています。「発射」「建築」「条件」「出現」「体力」「直径」などに対応します。ルビを含む行の高さと文字サイズも調整しています。

表示時だけ変換し、作品データ・部品ID・イベントの種類・入力欄に保存する作品名や銃の名前・数値は変更しません。説明の追加や設定画面の作り直しにも同じ表示処理を使い、毎フレーム同じ文言を表示する場合はDOMを作り直しません。新しい用語や異なる読み方が必要な場合は readings3d.js の辞書を更新します。
