# つくるラボ / Game Lab

小学生が「すぐ遊べるテンプレート」からゲームづくりを始めるための試作です。iPadのSafari向けのタッチ操作と、パソコンのキーボード操作に対応しています。

## 試作に入っているもの

- 見下ろし型シューティング。移動・自動照準・発射・当たり判定・体力・得点・クリア／再挑戦。
- 2400 × 1600 の広い世界と追従カメラ。敵・壁・星・ゴールの配置、移動、削除、ミニマップ。
- 日本語の動作ブロック。敵ごとに追跡・左右移動・接近時の発射／逃走を組み合わせ、並べ替えできます。ゲーム開始後、毎フレーム上から順に実行します。汎用のScratch互換ブロックエディターではありません。
- 弾の速さ・発射間隔・威力・同時発射数の変更。
- ブラウザへの自動保存とJSONファイルへの書き出し／読み込み。アカウント、外部ライブラリ、外部画像、通信APIは使いません。

## 3D FPS / TPS テンプレート

入口: https://gpz400r4649-wq.github.io/game-lab/3d.html

UE5のFPS/TPSテンプレートに着想を得た、ブラウザ向けの独立した試作です。UE5自体やUE5のアセットは使っていません。Three.js 0.180.0をMITライセンスで同梱しています（vendor/THREE-LICENSE.txt）。外部CDNへの接続なしで起動します。

- 空の60m四方のステージ。TPS / FPSをプレイ中も切り替え可能。
- 視点基準の移動、ドラッグによる視点操作、ジャンプ、重力、ブロック・足場との衝突と着地、TPSカメラの壁へのめり込み回避。
- ジャンプ・発射ボタンとマルチタッチ用移動スティック。PCはWASD / 矢印・スペース・F。
- 地面をタップしてブロック・足場・敵・星を追加。パーツの一覧、位置・高さ・大きさを数値で編集。
- 敵の追跡・左右移動・接近時の発射ブロックと、武器の速さ・威力・同時発射数の設定。
- 3D専用の自動保存とJSONファイルの保存・読み込み。2D作品とは別領域に保存。

### 置いて組み合わせる「ゲームづくり工房」

「持ちもの・銃をつくる」で、名前を付けた銃を最大８個まで登録できます。銃から出るものを「弾」「壁」「床」「屋根」から選びます。射撃の銃は、連射・拡散・威力などの用意済み設定を選ぶか、数値で調整できます。以前の作品には、元の武器の性能を引き継いだ射撃銃と、３種類の建築銃を補います。

#### 銃づくりと建築

- プレイ中は持ちもの欄をタップ、PCは数字1〜8で持ち替え。建築銃を持つと、狙った場所のプレビューを表示します。近い足場や地面を狙えないときは、手前約6mを候補にします。
- 緑のプレビューなら「建てる」ボタン / Fで配置。赤い場合は理由を表示します。自分との重なり、重複、遠すぎる場所、ステージ外への配置を防ぎます。
- 壁は幅4m・高さ3m、床は壁の内側に収まる板、屋根は壁の上に載る三角屋根。4mの配置間隔と3mの階の高さにそろえます。画面の向き・高さボタン、またはRと[ / ]で調整できます。
- 「１つもどす」は今回のプレイで建てた最後の部品を取り消します。元のステージの部品は削除しません。
- **「建築を作品に残す」**で建てた部品を編集用の作品に加え、自動保存して編集に戻ります。そのボタンを押さずに編集へ戻る・再挑戦する・ページを閉じると、プレイ中の建築は消えます。敵の撃破やアイテムの取得状況は編集用の作品に保存しません。
- 壁・床・屋根は編集画面から直接配置・複製・回転することもできます。「建築ひろば」のお手本には小さな家と建て足すための空間を用意しています。

射撃の弾数と建築資材は無制限です。部品数は元のステージとプレイ中の建築を合わせて150個まで。建築の破壊・窓や入口の編集、資材集め、オンライン対戦は未実装です。屋根は三角柱として当たり判定を持ちます。

#### お手本と部品

最初に「建築ひろば」「足場アスレチック」「宝さがし」「ロボット対戦」の４種類のお手本を選べます。それぞれ、地形や部品を用意してあり、まず遊んでから配置やルールを変えられます。お手本への切り替えは今の作品を置き換えるため、確認画面を表示します。必要な作品は先にファイルに保存してください。まっさらなステージから始める機能もあります。

用意済みの部品:

- **動く足場**：方向（左右・前後・上下）、移動範囲、速さを選択。乗っているプレイヤーを運びます。
- **ジャンプ台**：ふれると自動で大ジャンプ。飛ぶ強さを変更できます。
- **星・カギ・回復アイテム**：接触判定や取得後に消える処理を内蔵。星の得点や回復量を設定できます。カギは所持数を記録し、ドアが開いても消費しません。
- **ドア・ゴール**：星の数、カギの数、敵の全滅、条件なしからルールを選びます。ドアは条件達成で自動開放、ゴールは条件達成後にふれるとクリア。必要な星・カギが配置されていない場合は編集画面にヒントを表示します。
- **中間地点**：ふれると記録し、体力がなくなると自動でそこに復活。集めたものや撃破状況は保持し、再挑戦ボタンではステージ全体を初期化します。
- **ダメージ床**：ふれると体力が減ります。ダメージ量と床の大きさを調整できます。
- **敵ロボット**：追跡・見はり・射撃・動かない的から選択。自由な動作ブロックは「さらに工夫する」の中に置いています。
- **武器**：ふつう・れんしゃ・ひろがる・パワーから選び、必要なら細かく調整できます。

位置は方向ボタンで調整し、数値による位置・大きさの設定は折りたたんでいます。同じ部品を複製することもできます。以前の3D作品には不足している部品設定を読み込み時に補い、既存の敵プログラムは保持します。配色は部品ごとに固定です。

移動する足場や敵には経路探索や障害物回避を備えていません。動く足場の経路が壁・ほかの足場を横切らないように配置してください。ドアの鍵穴やゴールの条件に対応するアイテムは、同一ステージ内の共通の所持数で判定します。

3D版はWebGL 2に対応したブラウザが必要です。iPadは横向き推奨。実機Safariでのマルチタッチと性能の確認は未実施です。敵の移動は地面上の簡易動作で、経路探索・段差の乗り越え・任意の条件式を組む汎用ブロック言語は未実装です。

レースのテンプレートはまだ実装していません。作品のクラウド共有、複数作品の一覧、共同編集も今後の拡張です。

## 使い方

1. 「あそぶ」で最初からゲームが動きます。iPadでは左のスティックで移動、右のボタンで発射。PCでは矢印またはWASD、スペースで発射します。
2. 「つくる」でパーツを選び、ステージをタップして配置します。「えらぶ」で選択してドラッグすると移動できます。右下の矢印で編集範囲を動かします。
3. 敵を選ぶと動作ブロックを追加・削除・並べ替えできます。スタートの機体を選ぶと武器の設定を変更できます。
4. すべての敵を倒し、旗に到達するとクリアです。星は追加得点になります。
5. 共有端末では終了前に「作品の保存・読込」からファイルに保存してください。自動保存は同じブラウザ内の１作品分です。サイトデータ削除やプライベートブラウズでは保持されない場合があります。

## ローカル実行

Node.js 22以降を推奨。追加インストール不要です。

```sh
npm start
# http://127.0.0.1:4173
npm test
```
