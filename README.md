# つくるラボ / Game Lab

小学生が「すぐ遊べるテンプレート」からゲームづくりを始めるための試作です。iPadのSafari向けのタッチ操作と、パソコンのキーボード操作に対応しています。

## 試作に入っているもの

- 見下ろし型シューティング。移動・自動照準・発射・当たり判定・体力・得点・クリア／再挑戦。
- 2400 × 1600 の広い世界と追従カメラ。敵・壁・星・ゴールの配置、移動、削除、ミニマップ。
- 日本語の動作ブロック。敵ごとに追跡・左右移動・接近時の発射／逃走を組み合わせ、並べ替えできます。ゲーム開始後、毎フレーム上から順に実行します。汎用のScratch互換ブロックエディターではありません。
- 弾の速さ・発射間隔・威力・同時発射数の変更。
- ブラウザへの自動保存とJSONファイルへの書き出し／読み込み。アカウント、外部ライブラリ、外部画像、通信APIは使いません。

## 3D FPS / TPS テンプレート

入口: https://gpz400r4649-wq.github.io/game-lab/3d.html

UE5のFPS/TPSテンプレートに着想を得た、ブラウザ向けの独立した試作です。UE5自体やUE5のアセットは使っていません。Three.js 0.180.0をMITライセンスで同梱しています（vendor/THREE-LICENSE.txt）。外部CDNへの接続なしで起動します。

- 空の60m四方のステージ。TPS / FPSをプレイ中も切り替え可能。
- 視点基準の移動、ドラッグによる視点操作、ジャンプ、重力、ブロック・足場との衝突と着地、TPSカメラの壁へのめり込み回避。
- ジャンプ・発射ボタンとマルチタッチ用移動スティック。PCはWASD / 矢印・スペース・F。
- 地面をタップしてブロック・足場・敵・星を追加。パーツの一覧、位置・高さ・大きさを数値で編集。
- 敵の追跡・左右移動・接近時の発射ブロックと、武器の速さ・威力・同時発射数の設定。
- 3D専用の自動保存とJSONファイルの保存・読み込み。2D作品とは別領域に保存。

3D版はWebGL 2に対応したブラウザが必要です。iPadは横向き推奨。実機Safariでのマルチタッチと性能の確認は未実施です。敵の移動は地面上の簡易動作で、経路探索・段差の乗り越え・任意の条件式を組む汎用ブロック言語は未実装です。

レースのテンプレートはまだ実装していません。作品のクラウド共有、複数作品の一覧、共同編集も今後の拡張です。

## 使い方

1. 「あそぶ」で最初からゲームが動きます。iPadでは左のスティックで移動、右のボタンで発射。PCでは矢印またはWASD、スペースで発射します。
2. 「つくる」でパーツを選び、ステージをタップして配置します。「えらぶ」で選択してドラッグすると移動できます。右下の矢印で編集範囲を動かします。
3. 敵を選ぶと動作ブロックを追加・削除・並べ替えできます。スタートの機体を選ぶと武器の設定を変更できます。
4. すべての敵を倒し、旗に到達するとクリアです。星は追加得点になります。
5. 共有端末では終了前に「作品の保存・読込」からファイルに保存してください。自動保存は同じブラウザ内の１作品分です。サイトデータ削除やプライベートブラウズでは保持されない場合があります。

## ローカル実行

Node.js 22以降を推奨。追加インストール不要です。

```sh
npm start
# http://127.0.0.1:4173
npm test
```

## GitHub Pages

公開先: https://gpz400r4649-wq.github.io/game-lab/

リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。mainへのpushでテスト後、静的ファイルのみを公開します。初回の自動有効化が権限で失敗した場合は、この設定後 Actions から Publish Game Lab を再実行してください。

実機のiPadでの表示、マルチタッチ、ファイル保存の最終確認は授業前に行ってください。プログラムには任意のJavaScriptを実行する機能はありません。
