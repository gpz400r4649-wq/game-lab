# つくるラボ / Game Lab

小学生が、自分で部品を追加してゲームを作るためのブラウザ向け試作です。

## 制作の入口

- 新規3D作品は、地面・スタート・基本操作用の射撃銃１つだけです。敵、地形、家、アイテム、ゴール、クリア条件は配置していません。
- 完成したコースやゲームを読み込むお手本はありません。FPS / TPS は視点の切り替えです。
- 「つくる」で部品を置き、動きやルールを選び、「たしかめる」で自分の作品をテストします。
- 新しく置いた敵は動きません。行動タイプや動作ブロックを設定すると追跡・射撃などを始めます。
- 新しく置いたゴールは条件未設定です。クリア条件を自分で選ぶまでクリアできません。
- 2D版も、初期配置はスタートだけです。

以前に保存した作品は維持します。過去のお手本から作った作品も、敵の配置・行動・ゴールの条件を変更せず読み込みます。空の状態から作り直す場合は「空のステージから新しくつくる」を使ってください。必要な作品は先にファイルに保存できます。

## 3D FPS / TPS

入口: https://gpz400r4649-wq.github.io/game-lab/3d.html

UE5のFPS/TPSテンプレートに着想を得た、ブラウザ向けの独立した試作です。UE5自体やUE5のアセットは使っていません。Three.js 0.180.0をMITライセンスで同梱しています（vendor/THREE-LICENSE.txt）。外部CDNへの接続は不要です。

## 追加できる部品

編集画面のグリッドは4m間隔です。標準ブロックは横4m・奥行4m・高さ3m、床は4m四方で、マスにそろって隙間なく並びます。壁はマスの境界に吸着し、タップした端に合わせて向きを決めます。緑・赤の配置プレビューを表示し、上面へのタップは積み重ね、側面へのタップは横への接続になります。移動ボタンは横方向に１マス、標準ブロック・壁・床・屋根の高さ方向に１段ずつ移動します。既存作品の座標や寸法は読み込み時には変更しません。細かな寸法を自分で変更した部品では、標準サイズと異なる形になります。

- 壁・床・屋根・ブロック・足場。配置・複製・回転・位置や大きさの調整ができます。
- 動く足場。方向、範囲、速さを選択でき、乗ったプレイヤーを運びます。
- ジャンプ台。ふれると大ジャンプし、飛ぶ強さを変更できます。
- 敵ロボット。追跡・見はり・射撃・動かない的を選べます。動作ブロックは「さらに工夫する」にまとめています。
- 星・カギ・回復アイテム。得点・取得・回復などの処理を用意しています。カギは取得数で判定し、ドアが開いても消費しません。
- ドア・ゴール。星の数、カギの数、敵の全滅などの条件を選べます。足りないアイテム数は編集画面にヒントを表示します。
- セーブポイント。ふれると復活位置を記録し、体力がなくなるとそこから復活します。集めたものや撃破状況を保持します。
- ダメージ床。ダメージ量と床の大きさを調整できます。

これらは部品として用意してあり、新しい作品には配置しません。移動する足場や敵には経路探索を備えていないため、足場の経路が壁を横切らないように配置してください。3D版はWebGL 2対応ブラウザが必要です。実機Safariでのマルチタッチと性能の確認は未実施です。

## 弾の設定・破壊・スロープ

ブロック・壁・床・屋根・動く足場・スロープには、体力（1〜200）と「こわれる / こわれない」を設定できます。弾が当たると体力が減り、0になるとテスト中だけ消えます。命中時の点滅と残り体力を表示します。元の編集用データは変えません。壊した建築は「建築を作品に残す」の対象から外します。

スロープは4方向に回せる4m四方・高さ3mの部品です。低い側からジャンプなしで登れます。編集用の部品と、スロープを出す建築銃を用意していますが、新規ステージには配置・装備しません。

１マスを壁で囲んだ内側にもスロープを置けます。壁の境界との接合や、床とスロープの根元の接合を許可し、置く順番に依存しないようにしています。マス中央を横切る壁やスロープ同士の重複は防ぎます。スロープの上端から、周囲の壁を越えて上階の床へ移れます。

銃の設定:

- 弾の見た目：まるい弾 / ロケット弾。
- 当たったとき：直接ダメージ / 範囲内の敵とブロックに爆発ダメージ / ブロックで最大2回反射。
- 発射間隔：0.08〜2秒。威力：1〜30。同時発射数：1〜8発。
- 弾の直径：0.1〜1.2。速さ：5〜60。広がる角度：0〜45度。爆発範囲：1〜6。
- 建築銃から出すブロックの体力：1〜200。

マシンガンやロケットランチャーの「ヒント設定」を選んでから、各項目を調整することもできます。弾の種類と命中効果は別々に選べます。大きさは当たり判定にも反映し、持ち替えても発射済みの弾の設定は保持します。爆発は1回の衝突につき1回だけ発生し、自分の体力は減らしません。跳ね返りと組み合わせた弾は、次の衝突でも爆発します。爆風は範囲内の対象に同じ威力を与えます。

負荷を抑えるため、敵弾も含め画面内96発、演出16個、弾の寿命は射程・速さに応じて最長18秒、反射2回に制限しています。弾が上限に達したら、空きができるまで発射を抑えます。爆発から別の爆発を再帰的に起こす処理はありません。保存データの範囲検証と最大設定の連射テストを実施しています。すべてのiPadでの動作・クラッシュ回避を保証するものではなく、実機確認は未実施です。スコープは未実装です。

## 銃づくりと建築

「持ちもの・銃をつくる」で、名前を付けた銃を最大８個まで登録できます。銃から出るものを「弾」「壁」「床」「屋根」から選びます。新規作品に建築銃は入っていません。以前の作品で持ちもの情報がない場合は、元の武器の性能を引き継いだ射撃銃だけを補います。

- プレイ中は持ちもの欄をタップ、PCは数字1〜8で持ち替えます。
- 建築銃を自分で追加して持つと、狙った場所のプレビューが出ます。緑なら「建てる」/ Fで配置できます。
- 壁・床・三角屋根は4mの間隔と3mの階の高さにそろいます。向き・高さボタン、またはRと[ / ]で調整できます。
- 自分との重なり、重複、遠すぎる位置、ステージ外への配置を防ぎます。射撃の弾数と建築資材は無制限です。
- 「１つもどす」は今回のプレイで建てた最後の部品を取り消します。
- **「建築を作品に残す」**で建てた部品を編集用の作品へ加え、自動保存して編集へ戻ります。押さずに編集へ戻る・再挑戦する・ページを閉じると、プレイ中の建築は消えます。敵の撃破・アイテム取得状況は編集用の作品に保存しません。

部品数は元のステージとプレイ中の建築を合わせて150個まで。窓や入口の編集、資材集め、オンライン対戦は未実装です。屋根は三角柱として当たり判定を持ちます。

## 取ったとき・ふれたときのイベント

星・カギ・回復・ドア・セーブポイント・ゴールを選ぶと「イベントをつくる」が表示されます。見た目と役割を分け、元の効果を変更したり、起きることを最大6個まで組み合わせられます。元の効果をすべて外すことも、「元の役割にもどす」こともできます。

- 星・カギ・回復：ふれて取ると発生します。回復だけの設定は従来どおり体力が減ったときだけ拾えます。別のイベントを加えると、満タンでも拾えます。
- ドア：設定した条件を満たすと発生します。開ける効果を外して、別の役割にすることもできます。
- セーブポイント：ふれると発生します。記録に加えて銃をもらうなどを設定できます。
- ゴール：ふれて、設定した条件を満たすと発生します。クリア以外の役割にも変えられます。条件未設定では発生しません。

起きること：星の数を増やす、カギの数を増やす、得点を増やす、回復、指定したドアを開く、指定した銃を拾う、待機中の敵を出現させる、その場所をセーブポイントにする、クリアする。

「星を拾う → ロケットランチャーをもらう ＋ 敵が出現する」の作り方：

1. 「持ちもの・銃をつくる」で銃を用意し、「この銃をいつ使える？」を「イベントで拾って使う」にする。
2. 出現させたい場所に敵を置き、「いつ出現する？」を「イベントで出現を待つ」にする。行動タイプは別途選ぶ。
3. 星を置き、イベントを「設定した銃をひろう」「待機中の敵を出現させる」に変更して、それぞれの対象を選ぶ。
4. 「たしかめる」で星を取る。銃は拾うまで選択・発射できず、出現待ちの敵は表示・移動・攻撃・被弾をしません。

各部品のイベントはテストプレイにつき1回だけ起きます。敵は複製して増やすのではなく、配置済みの1体を有効にします。全滅条件には出現待ちの敵も含めます。ドアを開ける効果から別のイベントを再帰的に発生させる処理はありません。対象が削除された場合は設定画面に案内を出し、その効果だけをスキップします。

取得した銃・出現・回復・ドアの開閉・イベントの実行済み状態は編集作品を書き換えず、「やりなおす」で初期状態に戻ります。イベント未設定の保存済み作品は、元の星・カギ・回復・ドア・ゴールの効果を引き継ぎます。新規ステージは引き続き空です。


## iPadの同時タッチ操作

プレイ画面では移動スティック・視点ドラッグ・発射・ジャンプのタッチをゲーム操作として扱い、Safariのピンチ／ダブルタップ拡大や長押しメニューとの競合を抑えています。CSSの `touch-action` に加え、キャンセル可能な Touch/Gesture イベントを非passiveリスナーで処理します（[Appleのイベント資料](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/HandlingEvents/HandlingEvents.html)）。ゲーム画面内のタッチをdocumentのcapture段階で処理し、片方の指をスティックに残したまま別の指で連打する場合も、残る指の数にかかわらずtouchendを抑止します。通常の持ち替え・やりなおすボタンは、移動していないタップを1回のクリックとして処理します。持ちもの欄の横ドラッグも専用処理で維持します。プレイ中はルート要素にもtouch-action:noneを指定し、viewportの拡大制限を補助的に設定します（Safariのバージョンによってviewport制限が無視される場合があるため、これだけには依存しません）。編集・設定に戻ると元のviewport設定へ復元します。HTMLが読み込むアプリ・CSS・入力モジュールには更新番号を付け、旧ファイルのキャッシュを避けています。

入力は指のIDで管理し、別の指の終了でスティックや視点を解除しません。発射ボタンに複数の指が触れた場合は最後の指を離すまで連射を維持し、キャンセル・画面切替・フォーカス喪失時には解除します。イベント処理の自動テストは実施していますが、iPad実機での同時タッチとSafariのズーム抑制は未検証です。


## 小学生向けのよみがな

3D版の説明文・設定ラベル・イベント・ゲーム中の案内には、漢字の上にふりがな（HTML ruby）を付けています。短いボタンとネイティブの選択肢はひらがな表示にし、読みを併記して横に長くなりすぎないようにしています。「発射」「建築」「条件」「出現」「体力」「直径」などに対応します。ルビを含む行の高さと文字サイズも調整しています。

表示時だけ変換し、作品データ・部品ID・イベントの種類・入力欄に保存する作品名や銃の名前・数値は変更しません。説明の追加や設定画面の作り直しにも同じ表示処理を使い、毎フレーム同じ文言を表示する場合はDOMを作り直しません。新しい用語や異なる読み方が必要な場合は readings3d.js の辞書を更新します。


## 銃の性能を段階で調整する

「かんたん設定」は現在の性能と命中効果を比較して、該当するヒント名を表示します。選択後に「いまの設定」へ戻る問題を修正しました。数値や効果を変えてどのヒントとも一致しなくなった場合は「自分で調整中」と表示します。銃の名前や、最初から持つ／拾って使う設定は比較に含めません。

各性能は、ラジオボタンの3段階と「こまかく」、従来の数値入力を同じ行で使えます。段階を選ぶと右の数値が変わり、数値を直接入れると一致する段階または「こまかく」が選ばれます。発射間隔・威力・大きさ・発射数・速さ・広がり・爆発範囲・建築銃のブロック体力に対応し、従来の安全な上限を維持します。広がりは2発以上の同時発射で確認できます。

「当たったらどうなる？」はチェックボックスで組み合わせられます。

- ダメージ：当たった対象の体力を減らします。
- 爆発：衝突時に、その場所の範囲内の敵・ブロックにダメージを与えます。
- 跳ね返り：ブロックや地面で最大2回反射します。敵に当たった場合や3回目の衝突では消えます。

爆発＋跳ね返りでは、衝突するたびに爆発し、反射回数が残っていれば弾が進み続けます。ダメージも選んでいる場合、同じ命中で爆風と直接ダメージを二重に加算しません。跳ね返りだけを選ぶと体力を減らさずに反射します。すべて外すと命中時に消えるだけの弾にできます。旧形式の「跳ね返り」銃は従来の直接ダメージも保持します。弾数96・演出16・反射2回・寿命は射程・速さに応じて最長18秒の制限を維持し、発射済みの弾は後の銃設定変更の影響を受けません。

「中間地点」の画面上の表記を「セーブポイント」に統一しました。保存データ上のcheckpointという識別子は変更していません。セーブポイントはプレイ中の復活位置を記録する部品であり、テストプレイの途中状態をファイルへ保存する機能ではありません。


## 連射から反動・ブレを調整する

銃の設定順は「弾の種類・出る形・届く距離 → 発射間隔 → 反動・照準のブレ → 弾の強さ」です。

発射間隔を変更すると、その時点で反動とブレの初期値が連動します。段階選択でも数値入力でも同じ処理を使います。

|発射間隔|反動（1回の発射で上がる角度）|照準のブレ（最大角度）|
|---|---|---|
|ゆっくり・0.8秒|0.2度|0.3度|
|ふつう・0.25秒|1度|1度|
|はやい・0.08秒|4度|5度|

間の数値には段階間を補間した値を使います。初期値が入った後は、反動・ブレを個別に下げられます。発射間隔をもう一度変更するまで、ほかの性能の編集やテストプレイによって勝手に初期値へ戻しません。

「連射を速くする → テストする → 反動・ブレを下げる → もう一度試す」という作業を通じて、数値どうしのつながりと結果の違いを確かめられます。反動は視点が上がる動きとして反映し、連射中も合計12度まで、毎秒8度の速度で戻ります。照準のブレはランダムな射出方向のずれで、プレイ中の照準の丸はその広さを表します。反動の設定は0〜6度、ブレは0〜12度です。弾を出せなかった場合や建築銃には反動を加えません。

弾の出る形は横に広がる形／丸く広がる形を選べます。2発以上を同時に出すと形と広がりの違いが現れます。ブレは形全体のねらいをずらす設定として別に扱い、どの形でも弾の速さを維持します。

届く距離は2〜60mで、速さから独立して設定できます。跳ね返り後も残りの射程を使い、反射時に射程が復活することはありません。障害物・地面・ステージの外では設定距離より前に止まる場合があります。遅い弾でも射程まで届くよう寿命を計算し、安全上の上限を18秒にしています。画面内の弾96発・演出16個・反射2回の制限は維持します。

新しい項目がない保存済み作品には、反動0・ブレ0・射程60m・横に広がる形を補います。保存済み作品へ反動やブレを突然追加しません。各ヒント設定には射程・反動・ブレ・形も含め、設定名との一致判定にも使います。


## 数値の半角入力

3D版の数値欄は、整数にはinputmode=numeric、小数にはinputmode=decimalを指定します。ソフトウェアキーボードの種類は端末・OSの設定にも依存します。入力値は全角数字・全角小数点・全角プラスマイナスから半角へ変換し、保存データには数値を渡します。日本語入力の変換途中は反映せず、確定した時点で変換します。数値以外や空欄で確定した場合は直前の値へ戻し、従来の上限・下限も維持します。

ブラウザが全角文字を先に削除しないよう、表示欄にはtext型と数字キーボード指定を使い、spinbuttonの役割・範囲を付けています。上下矢印での調整も維持します。負数を使う位置欄には＋/−切り替えボタンがあり、マイナスキーのない数字キーボードでも調整できます。ラジオボタンと数値の連動、連射から反動・ブレへの連動も維持します。作品名や銃の名前などの文字入力欄は変更していません。


## 地面の銃アイテムとブロック破壊イベント

パレットの「銃アイテム」を置き、「ひろう銃」で持ちもの・銃づくりに登録した銃を選びます。触れるとその銃を入手して持ち替えます。「この銃を拾って使うにする」を選ぶと、拾う前は使えません。銃が未指定・削除済みの場合は勝手に拾って消えることはありません。新規ステージには銃アイテムを自動配置しません。

壁・床・屋根・スロープ・ブロック・足場・動く足場には「壊れたときのイベント」があります。**未設定では単に壊れて消えるだけ**です。イベント追加ボタンを押した場合にだけ、最初の候補として「このブロックをアイテムにする」が追加されます。最大6個まで組み合わせられます。

- このブロックをアイテムにする：壊れた場所へ小さなブロックアイテムが出ます。拾うと持ちものに個数付きで入り、拾った数だけグリッドに置き直せます。形・元の体力・動き・破壊イベントの設定を引き継ぎます。置けない場所では個数を減らしません。「１つもどす」では個数も返します。
- 銃アイテムを落とす：登録済みの銃を選ぶと、壊れた場所に銃アイテムが出ます。直接入手するイベントとは異なり、近づいて拾うまでは持ちものに入りません。
- 星・カギ・回復を落とす：選んだアイテムが出ます。各効果は拾ったときにだけ起きます。
- 既存の得点・ドア・敵の出現などのイベントも組み合わせられます。

複数の弾や爆風が同時に当たっても、１つのブロックの破壊イベントを重複実行しません。こわれないブロックはイベントを起こしません。落とす対象の設定途中や削除済み参照は安全にスキップします。

落ちたアイテムは少し落下して床へ着地し、発生から0.25秒後に拾えるようになります。プレイ中のドロップは画面内64個まで、ブロックの持ちものは8種類・各99個までです。同じ形・性能・設定のブロックはまとめます。空きがない場合は拾わず地面に残し、個数の上限を案内します。建築の150部品制限も維持します。

拾った銃・ドロップ・ブロックの持ちもの・破壊した状態は元の編集作品を変更せず、遊び直すと初期状態へ戻ります。置き直したブロックを保存したい場合は、既存の「建築を作品に残す」を使います。ドロップ自体を編集ステージへ自動追加することはありません。


## 建物への出入り

地面から床の厚み0.25mを歩いてまたげるよう、床を低い段差として扱います。１階の床・周囲の壁・高さ3mの屋根（または２階の床）を置いた建物で、入口から屋内へ歩いて入れます。壁・天井の当たり判定は維持し、頭の入らない低い天井の下へ段差で押し込まないようにしています。４方向の入口、部品の配置順、屋内のジャンプ、屋外への退出、スロープから上階への移動をテストしています。

### 広い3Dマップと建築

「マップ」から60 / 240 / 480 / 960m四方を選べます。全体図で場所を選び、「この場所を見る」で編集視点を移動、「ここをスタートにする」で開始位置を変更できます。部品やスタートが外にはみ出す縮小は行いません。以前の作品は60mのまま引き継ぎます。面積に応じた部品の自動生成はなく、部品150個・弾96個などの上限は維持します。

スロープの上面や高い側面に床を付けると、隣のマスの上階にそろいます。地面や床上のスロープから、ジャンプせず２階の床へ移れます。L字の壁の角では、接触した手前の面で移動を止めます。

建築銃を持った「たしかめる」中は、「たてる」ボタンのすぐ上にある「90° 回す」で向きを切り替えられます。PCのRキーでも切り替えられます。壁は狙ったマスの４辺を選び、スロープは登る方向を４方向に変えられます。iPadのタッチ操作はズーム防止と併用し、１タップで１回動作します。
